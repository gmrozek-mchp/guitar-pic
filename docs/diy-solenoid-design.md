# DIY Solenoid Design Guide

## Overview

This document details the design and construction of custom miniature solenoids for actuating keyboard switches in the Guitar Hero Bot project.

**Design goal:** Create quiet, low-force solenoids optimized for 50g keyboard switches using dual solenoids per switch (25g each).

---

## Design Requirements

| Parameter | Value | Notes |
|-----------|-------|-------|
| Target force | 25g (0.245N) per solenoid | Two solenoids per switch |
| Total force per switch | 50g | Matches typical keyboard switch |
| Stroke | 2-4mm | Keyboard switch travel |
| Response time | <20ms | Fast enough for Expert difficulty |
| Voltage | 12V DC | Standard, easy to source |
| Duty cycle | Pulsed (~10-20%) | Not continuous operation |
| Noise | Minimal | Key design goal |

## Solenoid Physics

### Force Equation

The force generated by a solenoid is approximately:

```
         (N × I)² × μ₀ × A
F  ≈  ─────────────────────
              2 × g²

Where:
  F  = Force (Newtons)
  N  = Number of wire turns
  I  = Current (Amperes)
  μ₀ = 4π × 10⁻⁷ H/m (permeability of free space)
  A  = Core cross-sectional area (m²)
  g  = Air gap between core and plunger (m)
```

### Key Insights

1. **Force ∝ (N × I)²** — Doubling turns OR current quadruples force
2. **Force ∝ 1/g²** — Force increases dramatically as gap closes
3. **Force ∝ A** — Larger core diameter = more force
4. **Iron core multiplies force** — Relative permeability of iron ~200-5000

## Winding Instructions

### Tools Needed

- Magnet wire spool with holder
- Hand drill or winding jig (optional)
- Multimeter (to verify resistance)
- Tape or glue (to secure wire ends)
- Wire strippers
- Fine sandpaper (to strip enamel from wire ends)

### Step-by-Step Winding

1. **Prepare bobbin**
   - 3D print bobbin per design above
   - Insert core (M4 bolt) through center hole
   - Secure core with nut or glue

2. **Start winding**
   - Leave 50mm lead wire for connection
   - Tape lead to bobbin flange
   - Begin winding at one flange, moving toward other

3. **Wind first layer**
   - Keep wire tight and turns touching
   - ~30 turns per layer (15mm ÷ 0.5mm wire pitch)
   - Guide wire with finger for even spacing

4. **Continue layers**
   - At end of each layer, reverse direction
   - Build up 7-8 layers
   - Total: ~230 turns

5. **Finish winding**
   - Leave 50mm lead wire at end
   - Secure with tape or clear nail polish
   - Verify resistance: should be ~6Ω (±1Ω)

6. **Strip wire ends**
   - Use fine sandpaper to remove enamel coating
   - Expose ~5mm of bare copper
   - Tin with solder

## Assembly

### Solenoid Assembly

1. **Install plunger**
   - Insert return spring into bobbin bore
   - Insert plunger (smaller bolt/rod)
   - Plunger should move freely 3-4mm

2. **Test actuation**
   - Apply 12V briefly
   - Plunger should pull in sharply
   - Should release when power removed

3. **Attach actuator**
   - Glue or thread pushrod to plunger end
   - Pushrod extends to switch stem

### Dual Solenoid Mount (Per Switch)

| Driver | Type | Channels | Max Current | Notes |
|--------|------|----------|-------------|-------|

| IRLZ44N | Logic MOSFET | 1 | 40A | Need external flyback diode |

| Parameter | Value |

| Average current (10% duty) | ~200mA |
| All 7 switches worst case | ~14A peak (brief) |

**Power supply:** 12V 5A should be sufficient (not all solenoids fire simultaneously at full current)

## Noise Reduction

DIY solenoids can be made quieter than commercial ones since you control construction:

### Techniques

1. **Soft plunger stop**
   - Add rubber/silicone pad where plunger seats
   - Eliminates metal-on-metal contact

2. **Damped return**
   - Use softer return spring
   - Slower release = quieter

3. **Housing isolation**
   - Mount solenoid in rubber grommets
   - Prevents vibration transfer

4. **Acoustic enclosure**
   - Cover solenoid with foam
   - Absorbs remaining sound

### Expected Noise

| Configuration | Sound Level |
|---------------|-------------|
| Bare DIY solenoid | Moderate click |
| With soft stops | Soft thud |
| With enclosure | Near silent |

## Testing & Validation

### Electrical Tests

| Test | Method | Expected |
|------|--------|----------|
| Resistance | Multimeter across leads | 5-7Ω |
| Continuity | Multimeter beep test | Continuous |
| Short to core | Measure lead to core | Open (no short) |

### Force Test

1. Mount solenoid pointing down
2. Attach small weight tray to plunger
3. Add weights until solenoid can't pull in
4. Record maximum force

**Target:** >25g at 3mm gap

### Response Time Test

1. Connect to oscilloscope + PIC
2. Measure time from GPIO high to plunger fully seated
3. Should be <20ms

## Troubleshooting

| Problem | Possible Cause | Solution |
|---------|---------------|----------|
| No movement | Winding open | Check continuity |
| Weak force | Too few turns | Rewind with more turns |
| Slow response | Too much resistance | Use thicker wire |
| Gets hot | Duty cycle too high | Add rest periods |
| Won't release | Residual magnetism | Use lower permeability core |
| Inconsistent | Plunger binding | Ensure alignment, lubricate |
