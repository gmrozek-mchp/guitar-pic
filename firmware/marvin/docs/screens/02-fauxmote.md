## What it does

fauxmote explores a different way to play: instead of physically pressing buttons on a real
guitar controller, it wirelessly pretends to *be* one, talking straight to the game console over
Bluetooth. It's a side experiment sitting alongside the main, physical approach — not the primary
path this project takes.

## Framing note

No chip/board name, no spec-sheet badge, no "Microchip inside" styling — just the name and a
one-line description. Keep the card visually a notch quieter than the others (smaller card,
lighter weight text) so it reads as a side exploration, not a headline part of the product story.
