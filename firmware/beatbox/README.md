# beatbox

The **beat-source node** for the Guitar Hero Bot system — a Microchip **dsPIC33AK512MPS512** (DSC)
that listens to line-level audio, runs real-time FFT beat/tempo detection, and (once on the bus)
publishes the result to the animation and lighting nodes: **position commands → [`lemmy`](../lemmy)**
and a **~5-parameter beat frame → [`lightshow`](../lightshow)**.

Imported from the standalone `dspicguitarhero` project. It currently runs **autonomously** (audio →
beat detect → local servo + RGB + WS2812 + UART telemetry) and is **not yet on the T1S bus**; the
re-scoping to a pure publisher is the work ahead.

## Build

Toolchain: **XC-DSC v3.31**. Build with CMake → Ninja (MPLAB project `beatbox`):

```
cmake -G Ninja \
  -DCMAKE_TOOLCHAIN_FILE=cmake/beatbox/default/.generated/toolchain.cmake \
  -B _build/beatbox/default \
  cmake/beatbox/default
cd _build/beatbox/default && ninja
```

Artifacts: `out/beatbox/default.elf` and `.hex` (flashable). The `cmake/` project tree is
regenerated by MPLAB from `.vscode/beatbox.mplab.json`; `_build/`, `out/`, and
`cmake/**/.generated/` are generated (see [`.gitignore`](.gitignore)).
